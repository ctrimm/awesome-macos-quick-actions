# Extract Audio from Video (MP3)

Extracts the audio track from each selected video and saves it as a high-quality MP3 (LAME VBR quality 4) next to the original (`<name>.mp3`), without re-encoding the video. If `ffmpeg` is not installed, a dialog explains how to install it (`brew install ffmpeg`). Requirements: optional `ffmpeg` (`brew install ffmpeg`).
