# Convert Video to Animated GIF

Converts each selected video to a 480px-wide animated GIF at 12 fps using a two-pass palette for good color quality. Output is saved next to the original as `<name>.gif`; the original is never modified. If `ffmpeg` is not installed, a dialog explains how to install it (`brew install ffmpeg`). Requirements: optional `ffmpeg` (`brew install ffmpeg`).
