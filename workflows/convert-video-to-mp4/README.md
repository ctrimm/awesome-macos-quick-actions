# Convert Video to MP4 (H.264)

Re-encodes each selected video to a widely compatible MP4 (H.264 video at CRF 23, AAC audio at 160 kbps), saved next to the original as `<name>-h264.mp4`. The original is never modified. If `ffmpeg` is not installed, a dialog explains how to install it (`brew install ffmpeg`). Requirements: optional `ffmpeg` (`brew install ffmpeg`).
